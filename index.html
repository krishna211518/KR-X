Learning Hub

Beginner-friendly roadmap. Learn one topic at a time.

LEVEL 01

Computer fundamentals

Hardware, software, input/output devices, memory, operating systems and number systems.

Practice: Identify five hardware components and explain their uses.

LEVEL 02

Web development

HTML structures a page, CSS styles it, and JavaScript adds interaction.

Practice: Build a simple personal webpage with a heading and a button.

LEVEL 03

Programming logic

Variables, conditions, loops, functions, arrays and debugging.

Practice: Write a small program that checks whether a number is even.

LEVEL 04

Cybersecurity basics

Passwords, phishing awareness, updates, backups, privacy and responsible security.

Practice: Review the safety checklist in Security Center.

LEVEL 05

Networking

IP addresses, routers, DNS, HTTP/HTTPS and how data travels online.

Practice: Draw a simple home network diagram.

LEVEL 06

AI foundations

Understand data, models, prompts, limitations, bias and responsible AI use.

Practice: Compare an AI answer with a trusted textbook source.
